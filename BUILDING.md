This is the grossly incomplete documentation for Eternity Works. As a repository, it stores only user-authored documents, examples, tutorials and write-ups, since the api reference is auto-generated from the source files.

## Building
eternity-works-docs currently relies on [Docsify-JS](https://docsify.js.org/#/) as its static content provider. Follow the instructions on that page to download the program, then `cd` into this repository's root and run `docsify serve ./` to start a localhost with the documentation loaded. Thereafter, any edits you make will be updated live.
